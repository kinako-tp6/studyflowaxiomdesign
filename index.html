進捗シートの作成

☁️ クラウド同期の有効化ガイド

💡 なぜ設定が必要？

GitHub Pages上では他人にデータを書き換えられないよう、あなた専用の無料データベース（Firebase）を使用する必要があります。完全無料で3分で接続できます！

1 データベースを作る（完全無料）

  1. Firebase Console にアクセスし、Googleアカウントでログイン。
  2. 「プロジェクトを追加」をクリックして任意のプロジェクト名（例: my-studyflow）を入力し進みます（Googleアナリティクスは無効でOK）。
  3. ダッシュボード内の「Webアプリアイコン（</>）」を選択。
  4. アプリのニックネームを入れて登録すると、画面に const firebaseConfig = { ... }; というコードが表示されるので、{ ... } の中身（波括弧を含むオブジェクト全体）を丸ごとコピーします。

2 認証とFirestoreを設定

  • ログイン機能の有効化：左メニューの「Build」➡️「Authentication」に入り、「始める」をクリック。ログインプロバイダで「Google」と「匿名ログイン」を有効にします。
  • データベースの有効化：左メニュー「Build」➡️「Firestore Database」に入り、「データベースの作成」をクリック。「テストモードで開始」または「本番モード」で東京リージョン（asia-northeast1）を選択し作成します。
